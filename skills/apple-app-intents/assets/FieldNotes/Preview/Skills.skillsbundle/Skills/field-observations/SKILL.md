---
name: field-observations
description: Logs wildlife, plant, and trail observations into an existing FieldNotes note and opens that note on request.
---
Use the log observation tool to record what someone saw. Fill in what was observed, how many, and where from the request. When no number is given, use one. When no place is given, leave the place empty instead of guessing.

Always add to a note that already exists. If the person doesn't say which note, or several notes share the name they use, ask which one they mean. Don't create a new note, rename a note, or pin a note to record an observation.

When the person asks to see or open the note, use the open note tool after logging, not before.

Several observations in one request are separate entries: log each one in the order the person gave them.
